# Dependency and data sources

This source export includes the project code and instructions. It includes no
installed dependencies, model weights, personal review database, credentials,
other competition code or private repository history.

- MCP Python SDK: https://github.com/modelcontextprotocol/python-sdk
- Transformers: https://github.com/huggingface/transformers
- PyTorch: https://github.com/pytorch/pytorch
- Qwen2.5-0.5B-Instruct: https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct
  (fixed revision and file hashes are in the model-lock JSON).
- CPSC public recall data: https://www.saferproducts.gov/RestWebServices/Recall

Dependencies and weights are obtained separately from upstream and retain their
own licenses and terms. No live recall API responses are bundled. The optional
synthetic demo fixture is fictional, is explicitly labelled, and is not evidence
about a real product or recall. Source-only mode does not
require model files. A project-source open-source license has not been granted
unless a separate LICENSE file is present.
